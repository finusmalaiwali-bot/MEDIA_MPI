02 / 09 Konsep Dasar

Apa itu Mikrokontroler?

Single Board Controller — kontrol spesifik

Mikrokontroler adalah chip yang dirancang untuk tugas kontrol tertanam (embedded).

Ciri-ciri

  • Sederhana & spesifik
  • Tanpa OS (bare-metal)
  • Hemat daya
  • Real-time

Contoh Populer

Arduino UNO ESP32 STM32

ESP32 WiFi + Bluetooth

03 / 09 Konsep Dasar

Apa itu SBC?

Single Board Computer — komputer mini

SBC adalah komputer lengkap dalam satu papan sirkuit tunggal.

Ciri-ciri

  • Ukuran ringkas
  • OS penuh (Linux)
  • Komputasi tinggi
  • Port lengkap

Contoh Populer

Raspberry Pi Orange Pi NVIDIA Jetson

Jetson khusus AI

04 / 09 Perbandingan

SBC vs Mikrokontroler

Apa perbedaan mendasarnya?

SBC

  • Fungsi: Komputasi serbaguna
  • OS: Linux / Windows
  • Aplikasi: Server, AI, Media
  • Harga: Rp 500.000+
VS

Mikrokontroler

  • Fungsi: Kontrol spesifik
  • OS: Tanpa OS / RTOS
  • Aplikasi: Sensor, Otomasi
  • Harga: Rp 50.000 - 200.000
SBC = Otak (komputer) MCU = Sistem Saraf (kontrol)
